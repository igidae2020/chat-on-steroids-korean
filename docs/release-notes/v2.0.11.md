## 2.0.11 — COS 관찰 경고와 실제 ChatGPT 오류 분리

공식 **v2.0.8** (`067c40dc64f3f108496aa9adf289f1e8c264fe9c`) 기반 한국어 · OpenCodex 배포판입니다.

- 10분 동안 화면에 변화가 없다는 확장의 자체 경고는 더 이상 ChatGPT 전송 실패로서 재로드를 요청하지 않습니다.
- 앱도 구형 확장이 보낸 동일한 경고를 구분합니다. 실제 모델·작업 증거에 따른 앱의 복구 판단은 유지합니다.
- 과거 기록을 포함해 해당 경고의 출처를 COS로 표시하며, 작업 중단이나 완료를 증명하지 않는다고 설명합니다.
- 실제 ChatGPT 전송 오류 처리, Pro의 최종 응답 증거 요구, 기존 Chrome 종료 후 자동 복구 및 OpenCodex 설정은 유지합니다.

앱과 확장 버전은 2.0.11이며 브리지 프로토콜은 **14**입니다. 이 변경이 모델의 응답 시간이나
Chrome 자체의 모든 충돌을 해결한다는 뜻은 아닙니다. 검사 통과와 설치·실기 결과는 별도로 확인해야 합니다.
