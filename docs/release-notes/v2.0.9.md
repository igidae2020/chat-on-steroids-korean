## 2.0.9 — 한국어 · OpenCodex 복구 수정

이 배포판의 기반은 공식 **v2.0.8**, 커밋 `067c40dc64f3f108496aa9adf289f1e8c264fe9c`입니다. 공식 2.0.9 릴리스가 아니라 한국어 배포판의 새 개정 번호입니다. 이전에 공개한 2.0.8 파일과 태그는 변경하지 않습니다.

### 변경 사항

- 확장 재시작 시 기존 ChatGPT 페이지에 전체 코드를 재주입하지 않습니다. 필요한 경우 동일 문서의 URL·초안·첨부·생성 상태를 전송 직전에 다시 확인하고 유휴 문서만 재로드합니다.
- 멈춘 탭의 응답을 무기한 기다리지 않고, 기존 DOM 감시를 해제하며, 메시지 접기에 React가 소유한 원본 자식 구조를 유지합니다.
- 응답 완료를 식별하는 차례 ID와 요약 전송 시각을 보존합니다. 실제 미전송 요약만 취소하고 같은 차례의 실패한 자동 요약을 계속 다시 시작하지 않습니다.
- 요약 전송 허가와 취소가 동시에 진행되지 않도록 체크포인트 대기열을 직렬화합니다. 재로드의 확정적인 무동작과 응답 유실을 구분합니다.
- 한국어 UI와 **OpenCodex / gpt-6-astra / high** 선택을 유지합니다. 모델과 추론은 계속 변경할 수 있습니다. 개인 설정·키·세션·백업은 배포물에 포함하지 않습니다.
- 한국어판은 공식 기준과 별도로 증가하는 배포 번호를 사용합니다. 공식 새 커밋의 자동 병합·검증·네이티브 패키지 검사를 유지하며 충돌·검사 실패 시 발행하지 않습니다.

**앱과 포함된 Chrome 확장을 함께 업데이트하세요.** 브리지 프로토콜은 **14**입니다. 구형 프로토콜 13 확장은 새 앱에서 호환 오류로 거부됩니다. 이 릴리스의 패키지 검사 통과는 모든 사용자 환경에서의 ChatGPT 웹 실기 검증을 의미하지 않습니다.

- `SHA256SUMS.txt` — SHA-256 checksums

The native source download accompanies the installers and is covered by the release checksums. Installed notices explain LGPL/MPL components and library replacement.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

Core supports Windows, macOS and Linux. Desktop control is available on Windows and optionally macOS with Screen Recording and Accessibility permissions. External plugins retain their own OS/service permissions. This project remains beta.
