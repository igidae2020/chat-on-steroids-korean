## 검증 기록

공식 원본에서 `npm ci`, `npm run verify`, macOS arm64 패키지 생성, bundle/runtime smoke를 수행했습니다.
원본 검사: 4,563개 일반 테스트 + 2개 shutdown 테스트 통과, 129개 환경별/선택적 테스트 제외.
이 결과는 한국어 통합본의 검사나 실제 ChatGPT 장시간 실행 결과를 대신하지 않습니다.

통합본 검사, 네이티브 Windows CI, Mac 설치와 실제 흐름은 완료된 증거만 아래에 기록합니다.

### 중간 CI

`1ebdeb2` 통합 중간본은 [CI 35257477625](https://github.com/igidae2020/chat-on-steroids-korean/actions/runs/35257477625)에서 Windows x64, macOS arm64, Linux x64의 필수 검사와 실제 플러그인 실행 검사를 모두 통과했습니다. 이 기록은 이후 한국어 카탈로그와 회귀 검사 추가분의 최종 CI를 대신하지 않습니다.

### 실제 설치 검증 범위

Mac 설치 후 별도 검증 대화에서 메시지 전송, 완료 기록, 자동 후속 진행, Compact & Resume, 브라우저 도구와 가져온 스킬을 확인합니다. 기존 대화/키/설정은 설치 전후 로컬 자료로 비교하며, 개인 자료나 키는 PR에 올리지 않습니다. 가상 시계의 장시간 회귀 검사는 실제 수 시간 운용과 구분합니다. Windows 네이티브 CI와 사용자의 두 Windows 컴퓨터에서의 실사용 또한 별개의 확인 항목입니다.

### 실제 요약 이전에서 발견한 추가 결함

2.1.14 실제 QA에서 요약 작성과 새 대화의 답변까지 진행됐으나, 첫 SPA 이동이 전송 확인 전의 관측 보류 상태를 해제해 recorder에 별도 세션이 생겼고 늦은 ACK가 소유권 충돌로 거부됐습니다. 2.1.15 개정에서는 이 최초 전송 소유자의 처리 경계를 수정합니다. 다른 로컬 세션을 빼앗거나 전역 대기 시간을 늘리는 방식은 채택하지 않습니다. 최종 실제 재검증 결과는 PR에 기록합니다.

- `content-script.test.ts`: 실제 전송 직후 최초 SPA 이동과 지연 ACK, 전송 허가/dispatch 거부 및 대기 중 다른 대화 이동을 회귀 검사합니다. 최초 결함은 원본에서 재현한 뒤 수정했습니다.

### 2.1.15 실제 재검증에서 남은 경계

요약 작성·새 대화 답변은 완료됐으나, 화면이 사용자 메시지의 마크다운을 렌더링하여 원문 전체 비교에 실패하는 전송 확인 경로가 재현됐습니다. 전송 ACK 미확인으로 공식 연결 보호 구간이 만료된 뒤 요청 귀속 과정에서 별도 세션이 생겼습니다. 2.1.16은 실제 전송에 귀속된 첫 DOM 변경에서 기존 원문 확인을 즉시 실행하도록 수정합니다. 타이머 지연을 모사한 회귀로 검사했으며, 토큰만으로 전송 성공을 인정하는 방식은 제외했습니다. 일반 메시지의 원문 비교와 공식 대기 시간·충돌 거부 정책은 유지합니다. 실사용 검증은 코드 검사와 구분합니다.
