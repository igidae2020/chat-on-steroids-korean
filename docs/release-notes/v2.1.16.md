## 2.1.16 — 한국어 · OpenCodex 개정 3

공식 v2.1.13 (`a4fe9726232edfbf67b97d6c716b6f653284739a`) 기반입니다. 공식 2.1.16를 의미하지 않습니다.

- 공식 번역 구조에 한국어 추가. 1,135개 항목과 언어 선택/설정 보존을 검증했습니다.
- OpenCodex를 공식 사용자 지정 OpenAI 호환 API의 프리셋으로 제공. 기존 모델·키 저장 방식을 유지합니다.
- 한국어 시간 초과 안내를 인식하고, 이전 응답 종료와 다음 응답 시작이 한 번에 전달될 때 새 응답의 복구가 누락되는 문제를 수정했습니다.
- 새 대화로 요약을 이어갈 때 첫 SPA 이동이 전송 확인 대기 상태를 해제하던 문제를 수정했습니다. 실제 전송 클릭에 귀속된 첫 이동만 보존하고, 전송 전 다른 대화로 이동하거나 거부되면 정상적으로 해제합니다.
- 마크다운 요약이 전송된 뒤 백그라운드 탭의 타이머 지연 때문에 원문 확인이 늦어지는 경로를 수정합니다. 실제 전송에 귀속된 첫 메시지 변경에서 기존 원문 확인을 즉시 깨우며, 표식만으로 전송 성공을 인정하지 않습니다.
- 충돌하는 이전 포크 정책 대신 공식 동작을 유지하며, 수동 Pro 요약 작성 대기는 공식 1시간 정책을 사용합니다.
- 앱과 포함된 확장을 함께 갱신하고 ChatGPT의 COS 연결 도구를 새로고침하세요.
- 세부 채택/제외 내역과 검증 범위는 [통합 기록](../korean-integration.md)을 참고하세요.

### 배포 파일 형식 (릴리스 게시 전 초안)

| Platform | Files |
| --- | --- |

| macOS Intel | `Chat-On-Steroids-macOS-x64.dmg` · `Chat-On-Steroids-macOS-x64.zip` |
| macOS Apple silicon | `Chat-On-Steroids-macOS-arm64.dmg` · `Chat-On-Steroids-macOS-arm64.zip` |
| Linux x64 | `Chat-On-Steroids-Linux-x64.AppImage` · `Chat-On-Steroids-Linux-x64.deb` |

릴리스 워크플로의 추가 산출물: `Chat-On-Steroids-Extension.zip`, `Chat-On-Steroids-Native-Sources.tar.gz` (corresponding native-library sources and replacement instructions), and `SHA256SUMS.txt`.

macOS builds are publisher-unsigned and unnotarized; macOS 13 Ventura or newer is required. On Linux, prefer the DEB on Debian/Ubuntu; AppImage can fall back to `--no-sandbox` where unprivileged user namespaces are disabled.
