# 공식 2.1.14 소스 기반 한국어판 통합 기록

## 기준과 범위

- 공식 소스: `6de3f963adc21766954c4a712ce00b42f3caf14c` (2.1.14 버전 선언; 검토 당시 최신 공개 릴리스는 2.1.13).
- 통합 브랜치: `integrate/upstream-2.1.14-korean`.
- 배포 식별: 앱/확장 2.1.19, 공식 2.1.14 소스 기반 한국어판 개정 1.
- 공식 추가 기능·언어·권한·전송 규칙·수동 Pro 요약 1시간 정책 유지.
- GitHub 릴리스 게시나 기존 PR 병합은 이 작업의 완료를 뜻하지 않으며 별도 작업이다.

## 제품 기능

- 공용 OpenCodex 라벨과 custom API 프리셋을 각각 독립 커밋으로 적용.
- 한국어 1,396개 키(공식 카탈로그 합집합 + OpenCodex). 공식에서 늘어난 262개 키 번역과 자리표시자를 검사.
- 공식 영어/스페인어/간체/번체 선택과 저장된 사용자 언어를 보존. 한국어 호스트의 미설정 기본값만 한국어.
- 공식 DOM과 파일·PDF·터미널·연결 진단·스킬·펫 기능 보존.
- 업데이트와 확장 다운로드는 기존 한국어판 저장소를 사용하고 버전별 확장을 선택.

## 공식 원본에서 완료한 검사

- `npm ci` 및 `npm run verify`: 일반 5,145개 + 종료 처리 6개 통과, 선택/환경별 129개 제외.
- `npm run dist:dir:mac:arm64`: 공식 원본 Mac arm64 패키지 생성 성공.
- `smoke-packaged-runtime` 및 `smoke-macos-bundle`: 네이티브 모듈, 번들 자원·실행 권한·아키텍처와 공식 ad-hoc seal 정책 검사 통과.
- 위 결과는 통합본의 검사나 설치본 실사용 증거가 아니다.

## 통합 중 검사

- 한국어/팝업 19개 검사와 타입 검사 통과.
- OpenCodex·업데이트·터널·패키징 근접 검사에서 127개 통과, 릴리스 노트 미작성 1개 실패. 2.1.19 릴리스 노트·변경 이력 추가 뒤 패키징 22개 통과.
- 전체 통합 검사, 서명·설치, Windows CI와 실제 사용 결과는 완료한 뒤 이 문서에 추가한다.

## 복구 패치와 배포 검증

[기능별 새 커밋 목록](korean-patch-series-2.1.14.json)에 원본과 분리된 적용 순서를 기록했다. 이전 기반 패치 목록은 이력으로 보존한다.

| 기능 | 결과 |
| --- | --- |
| 한국어 타임아웃 | 공식에서 실패 재현, 정확한 문구/다시 시도 버튼과 숨김·인용문 배제 적용 |
| 연속 응답 식별 | 공식에서 실패 재현, 새 응답 시작/이전 종료 두 순서와 실제 final 처리 보완 |
| 최초 SPA 이동 | 공식에서 실패 재현, 네이티브 전송 후 최초 목적지만 journal gate 유지. 허가 거부·무관한 이동은 제외 |
| canonical receipt wakeup | 공식 구현 사용. 옛 전용 observer 추가 안 함 |
| 과거 metadata 완료 판정 | 공식 구현 사용. 과거 질문/interim/final 재생·재시작 검사를 이식. 새 작업 부정 사례는 공식의 명시적 새 generation 계약에 맞춤 |
| 첫 자동 이전 Loop 답변 | 공식의 페이지 복구만으로 앱의 pending obligation이 생기지 않는 실패 재현. 기존 Goal ledger에 exact committed bootstrap/final 근거를 연결. 일반 no-MCP 예외로 확대하지 않음 |
| 재시작 근거 보존 | 3시간 뒤 및 늦은 pending 의무의 근거 소실 재현. 완료된 자동 이전의 근거만 해당 의무 수명에 맞게 보존 |
| 반복 재로드 | 공식 복구 정책에 맞춘 MCP 귀속 근거로 29×10분 가상 시계 검사 통과. 실제 4시간 실행 증거가 아님 |

복구 원본 비교 검사에서 8개 실패/745개 통과를 확인했고, 보완 후 관련 5개 파일 950개 통과. 첫 자동 이전 Loop API 경로 실패를 추가 재현한 뒤 bridge/recorder/continuation 597개 통과. 보존 실패 2개 재현 후 continuation/goal/bridge 692개 통과.

이 수치는 겹치는 근접 검사를 합산한 전체 테스트 수가 아니다. 서브에이전트의 공급자 오류/용량 제한으로 작업 중단이 있었으며, 부모가 실제 diff를 읽고 미완성 변경을 이어 구현·검증했다. 독립 최종 검토가 완료됐다고 표시하지 않는다.
