    연결 설정

    작업 공간을 ChatGPT에 연결하세요.

    처음 한 번만 설정하면 됩니다. 사용자 지정 MCP 앱을 사용하려면 ChatGPT 웹의 개발자 모드를 켜세요. 앱의 안내 기준으로 MCP 쓰기·수정은 Business·Enterprise·Edu에서 제공되며, Pro 사용자 지정 MCP는 읽기·가져오기로 안내됩니다. 실제 계정에서 제공하는 도구 권한을 확인하세요.

    1. 공유할 폴더 선택

      파일 도구는 승인한 폴더 안에서 작동합니다. 먼저 폴더를 선택하세요. 사용할 폴더가 없으면 터널이 시작되지 않습니다. 명령 실행 권한은 승인한 폴더로 제한되지 않습니다.

      아직 없음

    2. 터널 만들기

      OpenAI 플랫폼의 Tunnels(터널)에서 터널을 만드세요. 반드시 ChatGPT에서 사용하는 같은 워크스페이스를 선택하세요. 다른 워크스페이스의 터널은 표시되지 않습니다. 만든 터널의 ID를 복사하세요.

      화면·마우스·키보드는 별도 연결이므로 두 번째 터널이 필요합니다. 터널을 하나 더 만들어 ID를 입력하세요. 비워 두면 ChatGPT의 데스크톱 제어가 꺼집니다.

    3. API 키 만들기

      키 유형은 Restricted(제한됨)으로 만들고 Tunnels: Read와 Tunnels: Use만 허용하세요. 나머지는 None(없음)으로 두세요. 키는 다시 표시되지 않으므로 생성 직후 복사하세요.

    4. 터널 연결

      연결 기능을 사용하는 동안 앱을 실행해 두세요. 창을 닫아도 백그라운드에서 사용할 수 있습니다.

    5. ChatGPT에 연결 추가

      ChatGPT의 개발자 모드를 켜세요. 일반적으로 설정 → 앱 → 고급 설정에 있으며 워크스페이스 관리형 요금제는 앱 영역에서 사용자 지정 앱 메뉴를 제공합니다. 아래 카드마다 별도의 연결을 추가하세요. Core는 기본이며 Desktop은 사용할 때 추가합니다. Plugins는 플러그인 페이지에서 설정합니다. 각 카드는 ChatGPT의 별도 앱입니다:

      • 카드의 이름과 설명을 그대로 복사하세요. 도구 검색에 사용되므로 임의로 바꾸지 마세요.
      • 인증 항목은 맨 아래의 No authentication(인증 없음)을 선택하세요. 이 앱은 비밀 주소로 보호되며 별도의 로그인 인증을 사용하지 않습니다.
      자동 진행 전: ChatGPT의 도구 승인 설정을 확인하세요

      ChatGPT의 설정 → 플러그인(또는 앱)에서 이 연결을 선택하면 도구 승인 방식을 확인할 수 있습니다. 사용자가 모든 작업 허용(Allow all actions)을 선택하면 호출마다 승인을 묻지 않습니다. Desktop을 추가했다면 해당 연결도 별도로 확인하세요.

      개별 승인 방식에서는 승인 요청 때문에 Goal·Loop·작업자가 대기할 수 있습니다. 승인 방식을 바꿔도 COS의 폴더·도구 권한과 안전 검사는 그대로 적용됩니다.

    6. Chrome 확장 프로그램 추가

      chrome://extensions에서 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 선택한 뒤 아래 버튼으로 연 폴더를 지정하세요. 앱과 자동으로 연결되므로 코드를 입력할 필요가 없습니다.

      보조 에이전트 사용에 필수: 확장이 설치되고 ChatGPT에 연결되어 있어야 합니다. 확장이 없으면 Chat On Steroids가 작업자 대화를 식별하거나 열거나 작업을 전달할 수 없습니다.
