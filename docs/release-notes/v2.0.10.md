## 2.0.10 — 한국어 · OpenCodex 브라우저 자동 복구

공식 **v2.0.8** (`067c40dc64f3f108496aa9adf289f1e8c264fe9c`) 기반 한국어 배포판입니다.
기존 공개 태그와 설치 파일은 변경하지 않습니다.

### 변경 사항

- Chrome 종료 후 silence/no-tab 복구가 꺼진 확장을 기다리지 않고 기존 단일 시작 경로를 사용합니다.
- Windows에서 별도 자동화 user-data 디렉터리의 Chrome과 남은 렌더러를 작업용 Chrome으로 오인하지 않습니다.
  다른 프로필을 종료하거나 자격 증명을 복사하지 않습니다. 불확실한 프로세스 조회는 자동 실행 권한을 주지 않습니다.
- 실행 직전 현재 복구 요청·정지·차단·설정·대화 전환을 재검사합니다. 완료된 대화나 복구 Off인 일반 대화를 임의로 다시 열지 않습니다.
- 요약 응답의 provider request 연결, 되돌릴 수 있는 입력 실패 처리, 이미 전송된 긴 수동 요약 응답의 수명 보완을 포함합니다.
- 한국어 UI와 OpenCodex 설정을 유지합니다. 개인 데이터는 배포물에 포함하지 않습니다.

앱과 포함된 확장을 함께 업데이트하세요. 브리지 프로토콜은 **14**입니다.
이 수정은 브라우저 종료 후 복구를 위한 것으로 Chrome 자체의 모든 충돌 원인을 해결했다는 의미는 아닙니다.
