## 2.1.18 — 한국어 · OpenCodex 개정 5

공식 v2.1.13 기반 한국어판입니다. 공식 2.1.18을 의미하지 않습니다.

- 자동 요약 이전을 완료한 새 대화가 첫 응답에서 인수 확인만 하고 멈출 때, 켜진 Loop의 다음 진행을 연결합니다.
- 첫 최종 답변이 늦게 기록되어 응답 식별자가 없더라도, 같은 세션의 커밋된 이전 기록과 정확한 첫 응답을 확인합니다.
- 이 예외는 확인된 자동 이전의 첫 응답 한 번에만 적용합니다. 일반 응답의 MCP 호출 조건, 중지·차단·Loop Off, 새 사용자 입력과 전송 소유권 검사는 유지합니다.
- 대화 기록을 수동으로 바꾸거나, 재로드 타이머를 추가하거나, 불확실한 전송을 성공으로 승격하지 않습니다.
- 검증 결과와 한계는 [통합 기록](../korean-integration.md) 및 수정 PR에 기록합니다. 이 문서는 GitHub 릴리스 게시를 뜻하지 않습니다.
