## 2.1.17 — 한국어 · OpenCodex 개정 4

공식 v2.1.13 기반 한국어판입니다. 공식 2.1.17을 의미하지 않습니다.

- 완료된 답변이 `응답 완료 확인 중`에서 멈추는 문제를 수정합니다. 과거 메시지의 HTML·모델·식별 정보가 다시 기록될 때 증가하는 저장 순번을 새로운 작업으로 오인하던 완료 검사를 바로잡았습니다.
- 새 사용자 메시지, 새 응답, 실제로 변경된 최종 본문, 도구 실행, 진행 중인 턴과 대화 소유권 검사는 유지합니다.
- 재로드 주기나 공식 대기 정책을 변경하지 않습니다. 확장과 앱의 프로토콜도 그대로입니다.
- 소스 검사·설치·실사용 확인 결과는 [통합 기록](../korean-integration.md)에 구분해 기록합니다. 이 문서는 GitHub 릴리스 게시를 뜻하지 않습니다.
